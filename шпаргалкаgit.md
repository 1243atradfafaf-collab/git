# Команды Git

## git --version

Проверяет текущую установленную версию программы Git. Если Git установлен на компьютер, вы увидите его текущую версию.

```

git --version

 

![Скриншот: git --version]( https://github.com/1243atradfafaf-collab/git/blob/main/visrasd.PNG )

 

## git init

Инициализация репозитория: указываем папку, в которой git начнёт отслеживать изменения. В папке создаётся скрытая папка .git.

```

git init

```

![Скриншот: git init](https://github.com/1243atradfafaf-collab/git/blob/main/Снимок123.PNG?raw=true )

---

## git status

Показывает текущее состояние гита, есть ли изменения, которые нужно закоммитить (сохранить).

Чтобы вызвать ранее введённую команду, пользуемся стрелками на клавиатуре. Перебираем недавно введённые команды нажатием стрелки «вверх».

```

git status

```

![Скриншот: git status](https://github.com/1243atradfafaf-collab/git/blob/main/Снимок.PNG?raw=true )

---

## git add

Добавляет содержимое рабочего каталога в индекс (staging area) для последующего коммита. Эта команда дается после добавления файлов. Писать название целиком не обязательно: терминал дозаполнит данные автоматически.

```

git add

```

![Скриншот: git add](https://github.com/1243atradfafaf-collab/git/blob/main/Снимокasdf.PNG )

---

## git commit

Зафиксировать или сохранить.

По умолчанию git commit использует лишь этот индекс, так что вы можете использовать git add для сборки слепка вашего следующего коммита.

Команда git commit берёт все данные, добавленные в индекс с помощью git add, и сохраняет их слепок во внутренней базе данных, а затем сдвигает указатель текущей ветки на этот слепок.

```

git commit

```

![Скриншот: git commit]( https://github.com/1243atradfafaf-collab/git/blob/main/гндквытпоавтиппвоптоивоивтпивпивпивпивпи.PNG )

## git log

Журнал изменений.

Перед переключением версии файла в Git используйте команду git log, чтобы увидеть количество сохранений.

```

git log

```

![Скриншот: git log](https://github.com/1243atradfafaf-collab/git/blob/main/m%20mmmmmm.PNG)

Нажатие клавиши ‘q’ возвращает в исходное окно терминала.

---

## git checkout

Переключение между версиями.

Для работы нужно указать не только интересующий вас коммит, но и вернуться в тот, где работаем, при помощи команды git checkout master.

 

git checkout

 

![Скриншот: git checkout]( )

 

## git diff

Показывает разницу между текущим файлом и сохранённым.

Перед переключением версии файла в Git используйте команду git log, чтобы увидеть количество сохранений.

```

git diff

```

![Скриншот: git diff]( )

---

> Git отслеживает файлы по имени! Если изменить имя файла, необходимо добавить файл с новый именем + git commit
